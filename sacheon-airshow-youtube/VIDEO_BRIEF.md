# 2026 사천에어쇼 — AI 모션그래픽 영상 제작

당신은 전문 모션그래픽 디자이너이자 영상 제작 엔지니어입니다.

제가 제공하는 2026 사천에어쇼의 실제 취재 사진을 활용해 **유튜브용 60초 가로형 모션그래픽 영상**을 제작해주세요.

기획안이나 코드만 작성하지 말고, 실제 재생 가능한 MP4 파일까지 자동으로 완성하는 것이 목표입니다.

## 1. 영상 기본 설정

- 제목: 2026 사천에어쇼 — 하늘을 설계하다
- 길이: 정확히 60초
- 화면 비율: 16:9 가로형
- 해상도: 1920×1080 (Full HD)
- 프레임레이트: 30fps
- 파일 형식: MP4 (H.264)
- 플랫폼: 유튜브 일반 영상
- 분위기: 영화 예고편, 항공 다큐멘터리, 미래 기술 홍보영상
- 색감: 딥 네이비, 블루, 화이트
- 디자인: 미니멀하고 세련된 HUD, 홀로그램, 설계도, 디지털 스캔 그래픽

중요: 일반적인 사진 슬라이드쇼처럼 보이지 않도록 해주세요. 모든 장면에 목적 있는 움직임과 시각적 변화를 적용하되, 과도하게 촌스러운 효과는 사용하지 마세요.

## 2. 영상 구성

### SCENE 1. INTRO (0\~8초)

**하늘을 설계하다**

- 검은 배경에서 디지털 그리드 등장
- 항공기 윤곽이 청색 설계선으로 그려짐
- 설계선이 실제 항공기 사진으로 전환
- 카메라가 사진 속 항공기에 접근
- 타이틀: "하늘을 설계하다"
- 서브타이틀: "2026 SACHEON AIRSHOW"

### SCENE 2. KF-21 (8\~20초)

**설계도에서 현실로**

- 실제 KF-21 취재 사진 활용
- 항공기 윤곽선 추출
- 설계도 형태에서 실제 사진으로 변환
- 좌우 카메라 이동, 디지털 스캔, HUD 효과
- 항공기를 중심으로 역동적인 2.5D 모션 구현
- 자막: "KF-21 BORAMAE"

### SCENE 3. AIRCRAFT (20\~32초)

**사천의 하늘을 수놓은 항공기**

- 제공된 여러 항공기 사진 활용
- 화면을 2\~3개의 구역으로 분할
- 각 구역에서 서로 다른 항공기 사진 등장
- 스캔 효과와 디지털 타이포그래피 추가
- 와이드 화면의 공간감을 최대한 활용
- 확인된 기종명만 표시

### SCENE 4. BLACK EAGLES (32\~44초)

**하늘에 남긴 궤적**

- 블랙이글스 편대비행 사진 중심
- 실제 연막 경로를 따라 그래픽 라인 등장
- 좌우로 넓은 카메라 이동
- 연막 주변에 절제된 파티클 효과
- 편대비행 사진을 시네마틱하게 교차 편집
- 자막: "BLACK EAGLES"

### SCENE 5. HIGHLIGHT (44\~54초)

**하늘을 가로지르는 순간**

- 가장 역동적인 취재 사진들을 빠르게 교차 편집
- 화면 분할, 크로스 줌, 스피드 전환
- 항공기 클로즈업과 와이드 사진 번갈아 배치
- 자막:\
  "PRECISION"\
  "POWER"\
  "FLIGHT"

### SCENE 6. ENDING (54\~60초)

**2026 사천에어쇼**

- 가장 인상적인 와이드 사진을 전체 화면으로 표시
- 카메라가 서서히 뒤로 이동
- 엔딩 타이틀: "2026 SACHEON AIRSHOW"
- 하단 크레딧: "PHOTO BY AJP YOO NA-HYUN"
- 자연스럽게 페이드아웃

## 3. 가로 영상 디자인 원칙

- 1920×1080 화면을 적극적으로 활용하세요.
- 항공기 편대비행의 넓은 구도를 최대한 유지하세요.
- 원본 사진을 무리하게 확대하거나 늘리지 마세요.
- 세로 사진이 포함되면 블러 배경이나 분할 화면으로 자연스럽게 활용하세요.
- 주요 자막은 화면 가장자리에서 최소 100px 이상 떨어뜨리세요.
- 항공기 위치와 움직임의 방향을 고려해 자막을 배치하세요.
- 전체적인 인상은 전문 방송사의 항공 다큐멘터리 타이틀 시퀀스를 지향합니다.

## 4. 모션그래픽 요구사항

Python, FFmpeg, OpenCV, Pillow, SVG 등 사용 가능한 도구를 활용해 다음 효과를 구현하세요.

- Cinematic camera movement
- Ken Burns effect
- 2.5D parallax
- Aircraft outline animation
- Blueprint transformation
- HUD motion graphics
- Digital scanning
- Smoke trail graphics
- Particle animation
- Split-screen transitions
- Kinetic typography
- Cinematic zoom transitions

단, 효과를 많이 사용하는 것 자체가 목적이 아닙니다. 장면에 따라 적합한 효과를 선택하고 방송 영상 수준의 일관성을 유지하세요.

실제 사진의 항공기 기종, 형태, 식별 표시, 편대 구성은 변경하지 마세요.

AI 생성 또는 그래픽으로 만든 장면을 실제 촬영된 비행 영상처럼 오인하게 연출하지 마세요.

## 5. 음악 및 음향

- 사용자가 제공한 음악이 있으면 활용하세요.
- 제공한 음악이 없다면 무단으로 상업 음원을 다운로드하지 마세요.
- 코드로 생성 가능한 간단한 전자음과 전환 효과음을 사용할 수 있습니다.
- 음악을 확보할 수 없다면 무음으로 출력하세요.
- 내레이션 없이 자막 중심으로 제작하세요.

## 6. 자동 제작

- 제공된 사진을 자동으로 탐색하고 분류하세요.
- 사진 구도와 장면에 맞춰 자동 배치하세요.
- 사진마다 줌, 패닝 및 그래픽 효과를 적용하세요.
- 사진이 부족하면 서로 다른 크롭과 움직임으로 재활용하세요.
- 기종을 확실히 확인할 수 없으면 임의로 이름을 붙이지 마세요.
- 사용자의 수동 편집이 최소화되도록 구현하세요.
- 불필요한 확인 질문 없이 합리적인 기본값으로 진행하세요.

## 7. 렌더링 및 결과물

먼저 640×360 해상도의 짧은 샘플을 렌더링해 코드가 정상 작동하는지 검증하세요.

그다음 전체 영상을 1920×1080, 30fps로 렌더링하세요.

최종 파일:

현재 환경에서 MP4를 렌더링할 수 없는 경우, MacBook에서 실행 가능한 전체 프로젝트와 실행 명령을 제공하세요.
